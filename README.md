# Groundwork

A small, calm, mobile-first daily affirmations app. Plain HTML, CSS and JavaScript, no build step.

- **Home**: one affirmation for the day, your streak, and a button to start the routine.
- **Routine**: three short steps (how you feel, your evidence, your affirmation).
- **Evidence Bank**: save wins and moments of resilience.
- **Affirmations**: built-in statements for four moments, plus your own.

## Privacy

Everything you enter (Evidence Bank entries, your own affirmations, completion history) is stored only in your browser's `localStorage`. Nothing is sent anywhere, and nothing personal is in this repository. Clearing your browser's site data for this page erases it.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
